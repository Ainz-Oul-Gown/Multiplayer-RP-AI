# Гибридный ИИ-движок для текстовых RPG

## Цель

Проект строится как PWA с frontend на GitHub Pages, backend на Supabase и единым LLM-провайдером OpenRouter / MiMo v2.5.

## Конвейер хода

1. **Парсинг**: действие игрока отправляется в MiMo с системным промптом JSON-контракта.
2. **Математика**: Edge Function валидирует JSON, проверяет предметы, бросает d20 и обновляет PostgreSQL в транзакциях.
3. **Нарратив**: строгие факты, лор и состояние игрока отправляются в MiMo для литературного ответа Мастера.
4. **Трансляция**: итоговая запись попадает в `master_messages` и рассылается через Supabase Realtime.

## Первая итерация

- Минимальный PWA-каркас на Vite + React.
- Контракты промптов и d20-утилиты на frontend для прототипирования.
- Начальная миграция Supabase для миров, лора, сессий, игроков, инвентаря и сообщений Мастера.
- Черновая Edge Function `process-turn` как точка интеграции OpenRouter и Supabase.
